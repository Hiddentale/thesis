\begin{abstract}
    In 1978 Babai conjectured that minimal Cayley graphs have a bounded chromatic number. In 1995 he changed his mind and conjectured the opposite. After some years, in 2024, Garcia-Marco-Knauer found an answer for a subset of minimal Cayley graphs. Finally in 2026 they proved that, no, minimal cayley graphs do not have a bounded chromatic number.\todo{improve}
\end{abstract}

\subsection{Standard notation for paper}
\begin{definition}[Chromatic number]\label{chromatic}\cite{west}
        The smallest number of colors required to color the vertices of any graph \(G\), so that any adjacent vertices are never the same color, is called the chromatic number of  \(G\). Denoted as \(\chi(G)\).
    \end{definition}
    \begin{definition}[Circuit]\label{circuit}\cite{west}
        A \emph{circuit} is a closed walk that can't traverse the same edges twice.
    \end{definition}
    \begin{definition}[Cycle]\label{cycle}\cite{west}
        A \emph{cycle} is a circuit that can't traverse the same vertices twice.
    \end{definition}
    \begin{definition}[Generating set]
        Let \(G\) be a group and \(S\subseteq G\). If \(G\) can be constructed by group operations between elements of \(S\), then \(S\) is called a generating set of \(G\).
    \end{definition}
\subsection{Cayley graphs with small examples}
    \begin{definition}[Cayley Graphs]\label{cayley}
        Let \(G\) be a group, and let \(S\subseteq G\) be a generating set, construct the graph \(C(G,S)\) as follows:
        \begin{itemize}
            \item every \(g\in G\) is a vertex,
            \item for every ordered pair \((g, s)\), where \(s\cdot g_1 = g_2\) with \(s\in S\) and \(g_1, g_2\in G\), set an edge between \(g_1\) and \(g_2\), disallowing identical edges.
        \end{itemize}
        The resulting object, \(C(G,S)\), is then called a Cayley Graph.
    \end{definition}

\subsection{Minimal generating sets}
    \begin{definition}[Minimal generating set]
        Let \(G\) be a group with \(S\subseteq G\) a generating set. If removing any element of \(S\) results in \(S\) not being able to generate \(G\), we call \(S\) a minimal generating set.
    \end{definition}
    Note that a group can have multiple different generating sets, and they do not necessarily need to have the same amount of elements.
    \begin{example}
        Let \(G = \mathbb{Z}\) and \(S=\{2, 3\}\subseteq \mathbb{Z}\). It holds that \(\langle 3-2\rangle = \langle 1\rangle = \mathbb{Z}\), so \(S\) is a generating set. If we remove any of its elements, then it does not generate \(\mathbb{Z}\) anymore, so it is minimal. Also note that \(\{1\}\) is also a minimal generating set, with less elements than \(S\).\todo{improve}
    \end{example}

\subsection{Minimal Cayley graphs are no-lonely-color}
    Exposition here of Babai who studied minimal cayley graphs and figured out that no-lonely-color graphs naturally arise from them.
    \begin{definition}[Rainbow \cite{Hoffman2019}]
        Let \(G\) be an edge-colored graph, and let \(C\subseteq G\) be a circuit. If no edge color appears twice in this circuit, we call the circuit a \emph{Rainbow}.
    \end{definition}
    \begin{definition}[Rainbow-circuit-forbidden, adapted from \cite{Hoffman2019}]\todo{ask feedback}
        Let \(G\) be an edge-colored graph. If \(G\) contains no rainbow circuit with respect to the edge coloring, we call \(G\) \emph{rainbow-circuit-forbidden}.
    \end{definition}
    \begin{definition}[No-rainbow graph]\label{no-pied}\todo{ask feedback}
        Let \(G\) be a graph. If there \textbf{exists} an edge-coloring for \(G\) such that 
        \begin{itemize}
            \item \textbf{every} vertex can only have at most two edges of the same color,
            \item \textbf{every} circuit is rainbow-circuit-forbidden,
        \end{itemize}
        then we call \(G\) a \emph{no-rainbow graph}.
    \end{definition}
    Observe that only \emph{one} edge-coloring has to exist for this definition to be satisfied. Furthermore, each circuit can have thousands of different colors, the only requirement is that \emph{one} of those colors appears twice.

    \begin{definition}[No-lonely-color graph]\label{def:lonely}\todo{ask feedback}
        Let \(c\) be an edge coloring for a graph \(G\). A color is said to be lonely in a circuit \(C\) if only one edge of that circuit has that color. We call \(c\) no-lonely-color if for \textbf{every} circuit \(C\subseteq G\) it holds that

            \item every vertex can only have at most two edges of the same color,
            \item no color is lonely.
        \end{itemize}
        A graph is \emph{no-lonely-color} if there \textbf{exists} an edge coloring that is no-lonely-color.

    \begin{proposition}
        Every no-lonely-color graph is a no-rainbow graph.

        If no circuit exists with a color appearing once, then every circuit contains at least two edges of the same color.

        Let \(G\) be a group, and let \(S\subseteq G\) be a generating set. We call \(S\) \emph{quasi-irreducible} if the group generated by \(S\) equals \(G\), e.g.\todo{Isn't this literally the definition of a generating set?}

    \end{definition}
    Note that we only need one valid ordering for this to hold, as the following example shows.
    \begin{example}
        Let \(G = \mathbb{Z}\), and let \(S = \{2,3,4\}\). Since \(\langle 3-2\rangle = \langle 1\rangle = \mathbb{Z}\), also \(\langle S\rangle = \mathbb{Z}\).

    \end{example}

\subsection{Babai's conjectures}
    Together with the results from the previous section and Babai's own intuition, he conjectured the following
    \begin{conjecture}
        The chromatic number of any no-rainbow graph, and hence also no-lonely color graph, is bounded.
    \end{conjecture}
    Furthermore, he also conjectured a stronger statement.
    \begin{conjecture}
        The chromatic number of any minimal Cayley graph is bounded.
    \end{conjecture}
    Nevertheless, the faith in these conjectures did not last. In 1995 Babai wrote in the \emph{Handbook of Combinatorics}:
    \begin{quote}
        It is an open problem whether or not the chromatic number of finite minimal Cayley graphs is bounded. We conjecture it is not.
        \cite{Babai1995}
    \end{quote}
